# Atherstam Properties — website mock

Static site for Atherstam Properties Pvt. Ltd., Mylapore, Chennai.

- `website/` — the site (open `website/index.html`, or serve the folder with any static host)
- `logo/` — brand emblem source
- `proprety images/` — source photos (placeholders from Pinterest; replace with licensed/client photos before launch)

Run locally:

```bash
python -m http.server 5510 --directory website
```
